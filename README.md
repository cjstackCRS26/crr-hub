# College Recruiting Readiness · Student Hub

The CRR dashboard, its digital tools and the lesson pages, served together as one site so the tools can share a student's saved data.

- `index.html` – the dashboard (home page)
- `tools/<tool>/index.html` – the 11 digital tools
- `lessons/lessonN/index.html` – lesson pages (article, podcast, slides, toolkit)

Everything a student enters is stored in their own browser only. Nothing is sent to any server. Students can move their data with **My setup → Back up everything / Restore everything**.
